# 📈 Corporate Expense & Budget Analytics Engine

A robust, data-driven CLI application built with Python to monitor monthly budgets and track daily expenses. It features active error handling to prevent application crashes during invalid user inputs, making it a production-ready console application.

## 🚀 Live Demonstration

You can test the project live directly in your browser without downloading or installing anything:

* 💻 **Run Live Terminal:** [Click here to test on Replit](https://expense-tracker-system--FYTERNAMAN.replit.app)

## 🛠️ Tech Stack
* **Core Language:** Python 3
* **Key Concepts:** Exception Handling (`try-except`), Data Structures (Lists & Dictionaries), Dynamic Control Flow (`while` loops).
* **Deployment Platform:** Replit

## 📁 Repository Structure
* `expense_tracker.py` (or `main.py`) - The core application script containing the tracking logic.
* `README.md` - Project documentation and live links.
